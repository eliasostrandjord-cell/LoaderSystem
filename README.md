# Sonic CD Pocket

The 2011 Sonic CD engine running in the browser, made for iPhone (touch controls, home-screen app, game controllers).

* Engine: RSDKv3 decompilation by Rubberduckycooly and st×tic (https://github.com/RSDKModding/RSDKv3-Decompilation),
  original Retro Engine by Christian "Taxman" Whitehead. Built for the web with Emscripten; Plus DLC disabled (RSDK_AUTOBUILD).
* Uses libogg/libvorbis (Xiph.Org) and SDL2.
* No game data is included. Players load Data.rsdk from their own copy of the game; it stays on their device.
